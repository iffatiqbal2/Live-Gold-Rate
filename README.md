# BullionPK - Gold & Silver Rate Calculator 🇵🇰

A modern web application to track live gold prices and calculate jewelry costs based on Pakistani market standards.

## 🚀 Live Demo
[View Live Site](https://wondrous-licorice-40526d.netlify.app/)

## ✨ Features
- **Real-time Price Sync:** Automatically fetches international rates using MetalPriceAPI.
- **Smart Purity Selection:** Calculate prices for 18K, 20K, 21K, 22K, and 24K gold.
- **Firebase Backend:** Secure Google Login and Realtime Database caching.
- **Responsive Design:** Mobile-first UI built with Tailwind CSS.

## 🛠️ Built With
- **Frontend:** HTML, Tailwind CSS, JavaScript
- **Backend:** Firebase (Auth & Realtime Database)
- **Deployment:** Netlify
- **API:** MetalPriceAPI
